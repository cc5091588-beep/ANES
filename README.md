# ANES

Additional materials for student 14206159's dissertation, *Structural Differences in Selected Policy-Attitude Networks across U.S. Election Years: Evidence from ANES Samples, 2004–2024*.

- [Appendix](appendix/Appendix.docx): editable technical appendices A to D.
- [Results](results/Index.csv): figures, tables and links to their source values.
- [Analysis](analysis/README.md): R code, saved outputs, software requirements and running instructions.

The saved results can be checked and the supplied figures and tables regenerated without respondent data. A complete rebuild from the original data has not been verified for this copy. See the analysis instructions before running the notebooks.

Raw data and respondent-level intermediate files are not included. Package libraries, temporary files and local data paths are also excluded.
